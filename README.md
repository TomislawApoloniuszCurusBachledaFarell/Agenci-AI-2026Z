# Agenci-AI-2026Z


# Wizja
Gracze często mają problem ze znalezieniem gry odpowiadającej im oczekiwaniom w dobrej cenie. Wyszukanie trafnego tytułu w obecnych czasach wymaga ciągłego śledzenia Steam'owych premier i promocji na co nie każdy może sobie pozwolić. Nasz asystent AI pomoże im szybko znaleźć gry spełniające ich wymagania na podstawie aktualnych danych ze Steama.

Użytkownik może zapytać np. o grę przygodową dla dwóch osób w promocji, dobrze oceniane tytuły z konkretnym tagiem albo najciekawsze zniżki w wybranym gatunku. Asystent korzysta z API Steam, pobiera informacje o cenach, promocjach i opiniach, a następnie odpowiada w języku naturalnym.

Można też sprawdzić aktualne opinie o konkretnej grze, porównać ceny kilku tytułów albo poprosić o propozycje na podstawie preferencji (np. singleplayer, kooperacja, czas gry, poziom trudności) uzyskanych na postawie analizy biblioteki gracza. Asystent pomaga zarówno przy okazjonalnych zakupach podczas wyprzedaży, jak i przy systematycznym śledzeniu interesujących pozycji.
